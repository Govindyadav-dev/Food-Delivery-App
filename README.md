# Food Delivery Web App 🍽️

A modern and responsive **Food Delivery Web Application** built using **React.js and Vite**.
This project allows users to browse food items, search dishes, filter by categories, and add items to their dish/cart.

---

## 🚀 Features

* 🔍 Search food items
* 🍕 Category-wise filtering

  * Breakfast
  * Soups
  * Pasta
  * Pizza
  * Burger
* 🥗 Veg / Non-veg labels
* 💰 Dynamic price display
* 🛒 Add to dish / cart functionality
* 📱 Responsive UI for laptop and mobile
* ✨ Clean light theme design

---

## 🛠️ Tech Stack

* **React.js**
* **Vite**
* **JavaScript (ES6)**
* **TAILWINDCSS**
* **React Icons**

---

## 📸 Project Preview

The application includes:

* Search bar
* Category cards
* Food cards with images
* Price and type labels
* Add to dish button
